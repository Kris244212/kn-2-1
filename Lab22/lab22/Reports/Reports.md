# Лабораторна робота №22
## Тема: LSP: виявлення порушень і альтернативи

### 1. Початкова ієрархія
- Базовий клас: `Rectangle` з властивостями `Width` та `Height`.
- Похідний клас: `Square`, який автоматично змінює обидві сторони при зміні однієї.
- Проблема: Клієнтський код очікує, що Width та Height можна змінювати незалежно. `Square` порушує цю обіцянку → порушення LSP.

**Приклад:**
```csharp
Rectangle rect = new Square();
rect.Width = 5;
rect.Height = 10;
