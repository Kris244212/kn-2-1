📋 Легенда

IShape - Інтерфейс, який визначає контракт для всіх фігур
Rectangle & Square - Оригінальна помилкова реалізація (Square успадковується від Rectangle - порушує LSP)
RectangleLSP & SquareLSP - Правильна реалізація (обидва реалізують IShape окремо)
ShapeRecord - Модель даних для зберігання фігур в БД
ShapeDbContext - Entity Framework контекст для роботи з SQLite БД

✅ Правильна реалізація (LSP)

  • RectangleLSP реалізує IShape
  • SquareLSP реалізує IShape
  • Обидва можна використовувати як IShape
  • Немає спадкування між ними

❌ Помилкова реалізація

  • Square успадковується від Rectangle
  • Порушує контракт Rectangle
  • Має різні властивості (Size vs Width/Height)
  • Код очікує Rectangle, але отримує Square
