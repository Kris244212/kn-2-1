# Лабораторна робота №22
## Тема: LSP: виявлення порушень і альтернативи

### Мета
- Поглибити розуміння принципу підстановки Лісков (LSP).  
- Навчитися ідентифікувати порушення LSP у ієрархіях класів.  
- Розробити альтернативні рішення (зміна ієрархії або композиція), які дотримуються LSP.

### Структура проекту
lab22/
│
├── lab22.sln # Файл рішення
├── lab22/ # Основний проект
│ ├── Program.cs # Головний файл з Main
│ ├── Shapes/ # Класи фігур
│ │ ├── Rectangle.cs # Rectangle (порушує LSP)
│ │ ├── Square.cs # Square (порушує LSP)
│ │ ├── IShape.cs # Інтерфейс для альтернативи
│ │ ├── RectangleLSP.cs # Rectangle для LSP-сумісного рішення
│ │ └── SquareLSP.cs # Square для LSP-сумісного рішення
│ └── Reports/
│ └── Report.md # Аналіз LSP та обране рішення
└── README.md


### Використання
1. Відкрити рішення `lab22.sln` у Visual Studio або VS Code.  
2. Запустити проект.  
3. Консоль виведе:
   - Першу частину: демонстрація порушення LSP (Rectangle & Square).  
   - Другу частину: коректне рішення через інтерфейс `IShape` (RectangleLSP & SquareLSP).  

### Результати
- **Порушення LSP:** зміна Width та Height у Square впливає на обидві сторони, що призводить до некоректного обчислення площі.  
- **LSP-сумісне рішення:** використання інтерфейсу IShape дозволяє реалізувати Rectangle та Square окремо без порушення очікуваної поведінки.

### Використані принципи
- Liskov Substitution Principle (LSP)  
- Зміна ієрархії / інтерфейси  
- Основи ООП: наслідування, композиція
